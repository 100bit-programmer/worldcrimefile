World Crime File (월드 크라임 파일)

WCF Uploader — internal upload tool for the World Crime File YouTube channel

World Crime File is a Korean-language YouTube channel that publishes long-form videos explaining publicly released police body-camera footage, with Korean subtitles, commentary on the relevant laws and court decisions, and the outcome of each case.

WCF Uploader is a private command-line tool used only by the channel owner on their own computer. After an edited video has been reviewed, the tool uses the YouTube Data API to:

  • upload the video to the owner's own channel with the prepared title, description and tags,
  • set the custom thumbnail and scheduled publish time,
  • add the video to the channel's own playlists, and
  • check the processing status of the uploaded video.

The tool has no other users, does not access other people's YouTube accounts, and does not collect, analyze or share YouTube data.
