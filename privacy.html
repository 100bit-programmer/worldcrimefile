Privacy Policy

WCF Uploader · Last updated: September 23, 2026

WCF Uploader ("the tool") is an internal tool operated by the owner of the World Crime File YouTube channel ("we"). This policy explains what the tool accesses through YouTube API Services and how that information is handled.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Information the tool accesses

  • OAuth access to the owner's own YouTube channel, using the scopes youtube.upload and youtube, granted by the channel owner through Google's consent screen.
  • Basic channel information of the signed-in channel (channel ID, title, upload eligibility) to confirm that uploads go to the correct channel.
  • Information about videos the owner uploads with the tool (video ID, processing and privacy status).

The tool does not access any other user's account, and it does not collect names, email addresses, viewing history, comments, subscribers' data or analytics.

How the information is used

The information is used only to upload the owner's videos, set their metadata, thumbnails and publish schedule, add them to the owner's playlists, and confirm that each upload succeeded.

Storage and sharing

  • OAuth tokens and upload results (video IDs, timestamps) are stored only in local files on the channel owner's computer.
  • No information obtained through YouTube API Services is sent to any server operated by us or shared with, sold or disclosed to any third party.
  • The tool does not use cookies and does not place or read any information on users' devices other than these local files.

Retention and deletion

Local upload records are kept for as long as the channel owner needs them for their own records and can be deleted at any time by deleting the local files. Access can be revoked at any time on the Google security settings page: https://myaccount.google.com/permissions. When access is revoked, the stored token stops working and is deleted.

Changes and contact

If this policy changes, the updated version will be posted on this page with a new date. Questions: worldcrimefile.kr@gmail.com
